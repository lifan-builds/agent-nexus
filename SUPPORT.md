# Support

- **Bug or regression:** use the bug report template.
- **New target or capability:** use the feature request template.
- **Security issue:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **Setup help:** read [docs/quickstart.md](docs/quickstart.md), then include `nexus version`, platform, redacted manifest, and `nexus doctor` output.

Do not post API keys, tokens, private repository URLs, or unredacted home paths.
